# Pult extension

This repo is the VS Code extension of Pult's RFC 1 (`../pult/docs/pult/rfc-1.md`): a web extension against stock T3 Code servers, shipped as a VSIX, and the proof is Anton's daily use for all development. It is a repo of the Pult track; the track's own file, `../pult/TRACK.md`, is authoritative, and this repo's issues carry the `pult-extension` label.
